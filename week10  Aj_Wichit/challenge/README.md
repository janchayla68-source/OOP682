## ตำแหน่งไฟล์งาน
 ไฟล์สำหรับภารกิจท้าทายทั้งหมดอยู่ในโฟลเดอร์:
 wk10/challenge/log_viewer/

 ภายในประกอบด้วย:

 -CsvLogSource (คลาสใหม่)
 -LogFactory
 -main.py
 -โครงสร้างโปรแกรมทั้งหมดสำหรับทดสอบ OCP 


---

## สิ่งที่ดำเนินการ

1. สร้างคลาสใหม่ 'CSvLogSource'

- สืบทอดจาก 'ILogSource'
- รับผิดชอบอ่านไฟล์ ',csv' เท่านั้น

2. สร้าง 'LogFactory'

- ตรวจสอบนามสกุลไฟล์
- เลือกชนิดของ LogSource
- คืนค่า instance ที่ถูกต้อง

3. แก้ไข 'main.py'

- ให้เรียกใช้งานผ่าน Factory
- ไม่สร้างคลาสโดยตรง
- ไม่แก้ไขไฟล์ 'main_window.py' และ 'FileLogSource'

---

## วิธีการรันโปรแกรม
 
1. เปิด Terminal
2.  เข้าไปที่โฟลเดอร์:

cd wk10/challenge/log_viewer

3. รันโปรแกรมด้วยคำสั่ง:

python main.py

โปรแกรมสามารถอ่านไฟล์ '.log' และ '.csv' ได้ตามที่กำหนด 
โดยสามารถกำหนดชนิดของไฟล์ได้จากนามสกุลไฟล์
เพียงเปลี่ยนนามสกุลไฟล์เป็น '.log' หรือ '.csv' ระบบจะเลือกใช้ LogSource ที่เหมาะสมโดยอัตโนมัติผ่าน Factory

---

## ผลลัพธ์

- ระบบรองรับไฟล์ '.log' หรือ '.csv' 
- ไม่มีการแก้ไขคลาสเดิม
- สามารถเพิ่มชนิดไฟล์ใหม่ได้โดยการสร้างคลาสใหม่เท่านั้น
- เป็นไปตามหลัก Open/Closed Principle (OCP)
